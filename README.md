# JiraMate

JiraMate یک ابزار هوشمند برای بهینه‌سازی و مدیریت وظایف در Jira است که با بهره‌گیری از هوش مصنوعی، فرآیند مستندسازی و پیگیری تسک‌ها را ساده می‌کند.

## ویژگی‌ها
- **تولید خودکار:** خلاصه‌سازی و پیشنهاد متن برای تسک‌های Jira.
- **ادغام با LLM:** استفاده از مدل‌های OpenAI برای درک بهتر نیازمندی‌ها.
